# 文字風格規則（台灣繁體中文履歷）

目標語氣：專業但有人味，不公文腔也不口語。讀者是 hiring manager 與 HR，他們一天看很多份，你的句子要一眼能抓到「做了什麼、多少、結果」。

定稿前由 `editor` 代理去 AI 味：有 `humanizer-zh-tw` 外掛就用外掛，沒有就依 `references/humanizer_checklist.md`。寫手寫稿時先依本檔自律，讓 editor 少改。

## 標點與格式
- 中文句子一律全形標點：，。、；：？！「」（）。半形逗號、句號混進中文句子視為錯誤。
- 英文、數字、程式名之間用半形：`PyTorch/TensorFlow`、`Flask API + Android/iOS App`、`Precision 97.6%`。
- 日期統一 `YYYY/MM`，區間用 `～`：`2019/02～至今`。
- 金額寫單位：`682 萬元`。百分比前後對比用 `→`：`94.2%→99.74%`。
- 中英文之間留一個半形空格。
- 不用破折號（——、—）當連接詞；改句號、逗號或括號。
- 不留 HTML 註解、不放內部代號（部門代碼、IP、系統網址、未公開客戶名）。

## 用語
禁用（AI 味或中國用語）：優化、落地、痛點、打造、賦能、深耕、致力於、聚焦、凸顯、彰顯、體現、里程碑、此外、值得注意的是、顯著、全面、綜上所述、不可或缺、蓬勃發展、占比（用佔比）、校驗（用檢核）、彈窗（用跳出警示）、佈署（用部署）、用戶（用使用者）、數據驅動、視頻、服務器、軟件、硬件、信息、質量、默認、網絡、數據庫、調試、運行、高效、閉環、抓手、賽道。

專有名詞是公司內部系統正式名稱時（例如「智能廢鋼驗收系統」）保留原名，但不要把「智能」當一般形容詞用。

官方寫法：NVIDIA、JupyterHub、systemd、MiniCPM-V、PaddleOCR、YOLO11、Qwen3.5 27B。

## 句子
- 每條 bullet 一句話，20～35 字，動詞開頭。不用「負責、協助、參與」開頭；那是職責不是成果。
- 避免三段式排比（A、B、C 各三個）、避免「不只是…更是…」、避免每句同構（連續五條都「動詞＋名詞＋數字」會像模板，穿插一條長一點的敘述句）。
- 對比句「比起 X，更在意 Y」可以用一次，不要重複。
- 簡介 3～5 句，第一句就是定位，最後一句是目標職缺。不寫「熱愛學習、抗壓性強、善於溝通」這種通用特質。

## 數字
- 每個數字要有基準或樣本：`99%（196/198）`、`94.2%→99.74%（2026/01→07）`。
- 公司估算值要標「公司估算」「預估」。
- 沒有數字的成果用規模撐：席次、帳號數、案例數、部門數、廠區數；可以寫「使用數據追蹤中」。

## 自查（交稿前跑 `check_style.py`）
- 中文字數在上限內
- 無 HTML 註解
- 無半形標點貼中文
- 禁用詞為零
- 「主導」不超過 4 次
- 每條 bullet 動詞開頭
